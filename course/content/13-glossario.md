# 13 · Glossário

> Cada termo: definição exata em uma frase. Use a busca (🔍) para achar um termo.

| Termo | Definição |
|---|---|
| **A2A (Agent2Agent)** | Protocolo para agentes de serviços diferentes conversarem entre si. |
| **Agente** | Programa que usa um LLM para decidir passos e chamar ferramentas em laço até cumprir um objetivo. |
| **Allowlist** | Lista de itens permitidos; tudo fora dela é negado. |
| **async / await** | Sintaxe para esperar operações lentas sem bloquear o programa. |
| **Checkpoint** | Cópia salva do estado do grafo a cada passo. |
| **Checkpointer** | Componente do LangGraph que grava os checkpoints. |
| **Chunk** | Pedaço de um documento para indexar. |
| **Cosseno (distância)** | Medida de proximidade entre vetores baseada no ângulo. |
| **Docker** | Ferramenta que empacota e executa aplicações em contêineres. |
| **Docker Compose** | Arquivo que define e sobe vários contêineres juntos. |
| **Embedding** | Vetor numérico que representa o sentido de um texto. |
| **Eval** | Avaliação de qualidade com conjunto fixo de casos e métrica. |
| **Excessive Agency** | Risco de dar ao agente mais poder do que a tarefa exige. |
| **FastMCP** | Biblioteca Python para criar servidores MCP. |
| **Fan-out / fan-in** | Dividir trabalho em partes paralelas e depois juntar os resultados. |
| **Hit rate** | Proporção de buscas em que o resultado esperado apareceu entre os k primeiros. |
| **Human-in-the-loop** | Fluxo em que uma pessoa aprova ações antes de executarem. |
| **Host (MCP)** | Aplicação que contém o modelo e usa clientes MCP. |
| **Interrupt** | Função do LangGraph que pausa o grafo e espera uma resposta externa. |
| **JSON Schema** | Descrição formal da estrutura de um JSON. |
| **LangChain** | Biblioteca com interface comum para modelos, prompts e ferramentas. |
| **LangGraph** | Biblioteca para montar agentes como grafos com estado. |
| **LangMem** | Biblioteca de memória de longo prazo para agentes. |
| **LLM** | Modelo de linguagem de grande porte. |
| **MCP (Model Context Protocol)** | Protocolo aberto para conectar modelos a ferramentas e dados. |
| **Namespace** | Prefixo (tupla) que organiza e isola dados em um store. |
| **Node (nó)** | Função do grafo que recebe o estado e devolve mudanças. |
| **OWASP Top 10 for LLM** | Lista de riscos de segurança mais comuns em aplicações com LLM. |
| **Payload** | Metadados guardados junto com um vetor. |
| **pgvector** | Extensão do Postgres para vetores. |
| **Prompt** | Texto de entrada enviado ao modelo. |
| **Prompt injection** | Instruções maliciosas que levam o modelo a agir fora do esperado. |
| **Pydantic** | Biblioteca Python de modelos de dados com validação. |
| **Qdrant** | Banco de dados vetorial. |
| **RAG** | Buscar trechos relevantes e incluí-los no prompt antes de gerar a resposta. |
| **Reducer** | Regra que define como combinar valores de um campo do estado. |
| **Resource (MCP)** | Dado que um servidor MCP oferece para leitura. |
| **Saída estruturada** | Resposta do modelo em formato validado por schema. |
| **State (estado)** | Dados compartilhados entre os nós do grafo. |
| **stdio** | Transporte MCP por entrada/saída padrão de um processo local. |
| **Store** | Armazenamento de memória de longo prazo do LangGraph. |
| **Subgrafo** | Grafo compilado usado como nó de outro grafo. |
| **Supervisor** | Agente que decide qual agente roda em seguida. |
| **thread_id** | Identificador de uma execução cujo estado é salvo. |
| **Token (LLM)** | Unidade de texto que o modelo processa; base do custo. |
| **Token (autenticação)** | Credencial que autoriza acesso a uma API. |
| **Tool (ferramenta)** | Função com nome, descrição e parâmetros que o modelo pode pedir para executar. |
| **uv** | Gerenciador de projetos e pacotes Python. |
| **Vetor** | Lista de números que representa um ponto em um espaço. |
| **Webhook** | Chamada HTTP que um serviço envia quando um evento acontece. |
